# 🕯️ 3AM Tales: a free, fully automated multi-agent Instagram Reels system

Every day a team of AI agents makes and posts one part of an **illustrated Hindi story series** (emotional
family stories with a supernatural twist, friends and local legends, village secrets): animated-storybook
illustrations with the same Indian characters in every shot, fast cuts between speakers (a new picture every
~2–3 s), voiced dialogue, an original score, and a "To Be Continued / Follow For Part 2" ending. Each story
runs 2–3 parts; then a new one begins. It runs on GitHub Actions.

```
Analyst → Researcher → Writer ⇄ Critic → Voice cast → Illustrator → Composer → Editor → Caption → Publisher
   ▲        (new series or next part)          (portraits → shots → camera moves)                    │
   └──────────────────────── Memory (state/: series progress + character portraits) ◀────────────────┘
```

| Agent | Job |
|---|---|
| **Analyst** | Reads views, shares, saves and comments of past reels; writes "what works" lessons |
| **Researcher** | Continues the current series, or plans a fresh 2–3 part series (favouring formats that perform) |
| **Writer** | Writes the part as a fast-cut screenplay: ~30 illustrations and ~50 cuts, one spoken line per cut, cutting between speaker and listener close-ups |
| **Critic** | Independent editor: hook, emotional pull, tension, cliffhanger/twist, natural dialogue, visuals, safety |
| **Voice** | Each series alternates between a single storyteller (female/male alternating) and acted character dialogue; distinct voices for everyone (incl. children): Gemini TTS → Sarvam native Hindi voices → Microsoft Hindi voices, whichever is available; mastered |
| **Illustrator** | Draws a reference portrait of each character once per series, then every illustration using those portraits; Gemini inspects all drawings and redraws bad ones |
| **Animator** | Turns each picture into a living 3D shot: an open-source depth model makes near things move more than the background (parallax), plus drifting fog, floating dust/embers, lantern flicker, and flash-and-shake on scares |
| **Composer** | Writes an original score that follows each shot's mood (calm → uneasy → tense → scare), with booms on scares |
| **Editor** | Cuts on the dialogue, crossfades, watermark, end card, music ducking under voices, −14 LUFS master |
| **QA** | Checks the finished reel (length, size, audio, loudness, black or silent gaps, failed drawings) and blocks posting if something's wrong |
| **Caption** | "Series Title \| Part 1/2" caption, comment-bait question, call to action, hashtags |
| **Publisher** | Posts through the official Instagram API |

**Output:** 1080×1920, 30 fps, H.264 CRF 18, AAC 128 kbps 48 kHz, −14 LUFS, about 2.5–3.5 minutes per part.

## Setup

Steps 1–5 are the same as before (Instagram professional account, Meta token, Gemini key, GitHub repo,
secrets). The new part is **Cloudflare**, for the illustrations:

### Cloudflare (free, ~5 minutes)
1. Sign up at **dash.cloudflare.com** (free plan; no card needed for Workers AI's free allowance).
2. **Account ID:** on the dashboard home, open **Account home**; the Account ID is shown in the right-hand
   panel (it's also the long code in the address bar: `dash.cloudflare.com/<account id>/…`). Copy it.
3. **API token:** click your profile icon → **My Profile → API Tokens → Create Token**. Use the
   **Workers AI** template → **Continue to summary → Create Token**. Copy the token (it's shown once).
4. In GitHub: **Settings → Secrets and variables → Actions → New repository secret**, add:

| Name | Value |
|---|---|
| `CF_ACCOUNT_ID` | your Cloudflare account ID |
| `CF_API_TOKEN` | the token from step 3 |

Your full secret list is then: `GEMINI_API_KEY`, `CF_ACCOUNT_ID`, `CF_API_TOKEN`, `IG_ACCESS_TOKEN`,
`IG_USER_ID`, and optionally `SARVAM_API_KEY`. (`PIXABAY_API_KEY` is no longer used; you can delete it.)

Optional: a free account at **aihorde.net** gives an API key for faster backup illustrations; add it as
`AIHORDE_API_KEY`.

### Google AI Pro: Nano Banana pictures and reliable Gemini (recommended)
Your Google AI Pro plan includes **$10 (≈ ₹850) of Google Cloud credit every month** for the Gemini API.
Linking it unlocks Nano Banana (Gemini's image model: the best faces, consistency and storybook look) and
removes the free-tier "quota exceeded" errors. The system spends it carefully: Nano Banana draws the character
portraits and the ~6 pictures that stay on screen longest (≈ $0.30 a reel, ≈ $8–9 a month for daily posts), and
`billing.monthly_budget_usd` (default $9) stops paid drawing for the rest of the month before the credit runs out.
1. Open **developers.google.com/profile** (Google Developer Program) → **My Benefits** → activate the monthly
   Google Cloud credit and choose (or create) a **Cloud billing account**. Tick "always use this billing account".
2. Open **aistudio.google.com** → **API keys** → on your key's project choose **Set up billing** and pick that
   billing account. (Your existing `GEMINI_API_KEY` keeps working; nothing to change in GitHub.)
3. Safety net: **console.cloud.google.com/billing → Budgets & alerts → Create budget** of ₹850/month with email
   alerts, so you're told if anything ever goes over the credit.
Without step 2 the system simply skips Nano Banana and draws everything with Cloudflare.

### Sarvam voices (optional, best Hindi)
Sign up at **dashboard.sarvam.ai**, create an API key, and add it as the secret `SARVAM_API_KEY`. New accounts
get ₹100 free credit (~15–20 reels). To always use Sarvam first, change `voice.engines` in `config.yaml` to
`["sarvam", "gemini", "edge"]`.

### Test, then go live
**Actions → Daily horror reel → Run workflow** and pick a **mode**:
- **preview** (default, ~8 min): the first ~12 cuts (~30 s) plus all character portraits and drawings. Cheap
  (~1,500 Cloudflare neurons), perfect for checking the art style, character consistency and voices.
- **dry_run** (~25–40 min): the full reel, not posted.
- **post**: makes the reel and posts it (only if the QA check passes).

Download **reel-N** from the run's Artifacts: the video, `post-….json` (script, caption, QA report) and a
`pictures-…` folder with every illustration. Preview and dry runs never advance the series.
Cloudflare's free allowance is ~10,000 neurons a day (resets 5:30 AM IST): a full reel uses ~6,000–7,000, so do
at most one full dry run and one preview per day. The schedule posts daily at about 9:17 PM IST (live around 9:45 PM).

## Customising (`config.yaml`)
- **Watermark:** `channel.watermark` (set it to your Instagram handle).
- **Story types:** `formats`. **Parts per story:** `story.parts_per_series` (the agent decides within it). **Type run length:** `format_block_reels`. **Length:** `story.min_seconds` / `max_seconds`.
- **Art style:** `visuals.style`, `night_palette`; camera movement: `visuals.motion_strength`.
- **Subtitles:** `video.subtitles: true` adds Hinglish subtitles coloured per character (off by default).
- **Music:** `music.volume`, or `music.enabled: false`.
- **Voices:** `voice.style` (`narrator` by default, like the reference reels; `mix` or `dialogue`), `voice.narrator_gender`, `voice.sarvam_narrator` (try priya / neha / simran), `voice.gemini_voices`, `voice.narrator_gemini_voice`, `voice.engines` order.
- **3D motion:** `visuals.motion_strength`, `visuals.depth_model`, `visuals.atmosphere` (fog, dust, flicker).

## Troubleshooting
| Log message | Meaning / fix |
|---|---|
| `CF_ACCOUNT_ID / CF_API_TOKEN not set` | Add the Cloudflare secrets; until then the backup generator is used |
| `cloudflare unavailable (… QUOTA …)` | Today's free Cloudflare allowance is used up; the rest of the reel uses the backup generator. Resets 5:30 AM IST |
| `Cloudflare rejected the token/account` | Re-check `CF_ACCOUNT_ID` and recreate the token with the Workers AI template |
| `shot N: could not draw … reusing previous image` | One illustration was refused or failed; the previous one is reused with a different camera move |
| `Gemini TTS unavailable … switching to Microsoft Hindi voices` | Gemini voices aren't on your free tier today; Microsoft voices are used |
| `The free Gemini quota is used up for today` | Too many runs today; it resets around 1:30 PM IST |
| `QA FAILED … NOT POSTED` | The finished reel had a problem (listed in the log and in post-….json); nothing was posted. Download the artifact to see it |
| `quality check: redrew I7 …` | Normal: the inspector found a bad drawing and fixed it |
| `sarvam voices unavailable (HTTP 403/402)` | Sarvam key wrong or credit used up; the next engine is used |
| `gemini unavailable (… need billing linked …)` | Nano Banana needs the Pro credit linked (see above); Cloudflare draws instead |
| `this month's Gemini budget is used` | The monthly cap was reached; free drawing until next month (change `billing.monthly_budget_usd`) |
| `direct upload not available … using backup route` | Normal for some login types; the reel is posted via a temporary 24-hour link |

## Ground rules built in
- Official Instagram API only: no passwords, no scraping, no follow/like/DM bots.
- Original stories and characters every time; the Critic blocks gore, self-harm, real victims, named real
  people and anything mocking a religion or community. Captions mark stories as fiction.
- Instagram allows up to 100 API posts a day; this posts 1.


## v7 — the reference-reel style

- **Story:** a new main format, *village folk-horror kahani told by a storyteller* (girl + maa/dadi, peepal tree,
  full moon, a local legend, family love and sacrifice). It's used for every other new series; the others rotate.
  Once the Analyst has data, the best-performing formats get chosen more often.
- **Rhythm:** 2.5–3.5 minute parts, a recurring "motif" wide shot (the village under the moon) as chapter breaks,
  slow 6–8 s holds during calm narration and fast 1–2 s emotional close-up cuts at the peaks.
- **Voice:** one female storyteller (85–95% narration), characters speak only at the big moments.
- **Pictures:** a style prompt tuned to the reference (bold outlines, glossy expressive eyes, cobalt moonlight vs warm
  lantern light). Character portraits and the longest-on-screen shots use Cloudflare's higher-quality FLUX.2 klein 9B
  model, inside the same free 10,000 daily neurons (the log line "Cloudflare ≈ N of 10,000" shows the day's use).
- **Music:** a melancholic piano theme generated fresh for each reel (repeated and varied like a film score) over
  the dark pad, louder in the mix and dipping less under the voice.

## How stories and story types change (v7.1)

- **The agent decides everything itself:** each new story (title, region, legend, characters, twist) and how many
  daily parts it needs (1-3). A story continues part by part every day until its last part, then a new one starts.
- **Story type changes every 2-3 reels** (`format_block_reels`), so the channel never feels repetitive.
- **Gradual diversification:** the channel starts with the reference style (village kahani, family horror). New
  story types unlock as it grows: village secrets (after 4 reels), friends and a legend (8), night journeys (12),
  city night mysteries (16), old havelis (22), mind-bending mysteries (30). Every new story must differ from the last
  three in region of India, setting, kind of legend and hero; after 9 stories the agent is pushed to experiment more.
- **Always for an Indian audience:** Indian places, names, families, beliefs and folk legends, in Hindi-heavy Hinglish.
- **Learns from results:** once views/shares/saves data exists, better-performing story types are chosen more often.

## v7.1.13 — a strong first 5 seconds, faster cutting, cleaner pictures, better sound
**The first 5 seconds**
- Every reel opens with a *cold open*: a flash-forward to the scariest moment of the part (an extreme close-up, one
  shocking line of at most 10 words), then "but it all began…", and only then the calm village shot. If the writer
  still opens on calm scenery, the system moves the scariest short line to the front by itself.
- The first frame lands with a white flash, a camera shake and a deep boom (plus a real horror sting from Freesound).
  No fade-in from black: the picture and the voice start at once (0.15 s).
- A big on-screen hook line for the first 3 seconds, for people scrolling with the sound off.
- The last line echoes the cold open, so the reel loops when Instagram replays it.

**Cuts and sync**
- No picture stays longer than ~6 s: long narration lines get extra cuts at the storyteller's breaths, each a new
  angle on the drawing (a punch-in on the face, then a different camera move).
- Up to 24 different pictures per part (was 18); the motif shot comes back at most twice, nothing more than 3 times,
  never twice in a row. The Critic checks the cold open, line length and repeats.

**Pictures**
- Fixed "setting" for the whole series (region, houses, trees) added to every picture, so the story never jumps from a
  plains village to a pine forest; the picture check rejects things the story doesn't have (cars, hills, modern items).
- Props that come out as gibberish text (signboards, posters, letters, newspapers) are removed from picture prompts;
  comic-panel / collage pictures are forbidden and rejected by the picture check.

**Sound**
- Voice: clearer and crisper (less 300 Hz mud, more presence at 3-6 kHz, a de-esser).
- Music: low end trimmed under the voice, wider stereo; sound effects +3 dB; ambience starts at once.
- Master: -14 LUFS with 2 dB of peak headroom and a limiter (no clipping after Instagram's re-encode); (AAC stays 128 kbps: Instagram's spec).

**End card**: 3 s (was 4), big bold text in the middle of the screen, above Instagram's caption area.

### On-time posting (v7.1.13)
GitHub starts scheduled runs late (often by hours) and sometimes skips one, so the workflow now triggers 7 times
between 1:17 PM and 9:17 PM IST. **The first run that starts after 4:17 PM makes the reel immediately, waits, and
posts at exactly 9:17 PM IST** (YouTube and Instagram). Every other run skips in about 2 minutes:
- too early (before 4:17 PM; GitHub stops any job after 6 h, so a run can't wait longer than that),
- or today's reel already went out (any post after 4:17 PM today, manual ones included). A manual post earlier in
  the day does not stop the 9:17 PM post.
If a run fails, the next trigger automatically tries again. If GitHub is so late that no run starts before 9:17 PM,
the reel is posted as soon as it is ready, until midnight; it never posts in the middle of the night.
While one run is waiting for 9:17 PM, GitHub keeps only one later trigger queued and marks the others "cancelled"
(grey): that is normal. Change the time in `config.yaml` → `schedule.post_time_ist`.
Manual runs: mode `post` posts at once (but never within 3 h of another post); `auto` behaves like the schedule.

## v7.1.15 — review fixes: never post twice, degrade instead of failing
**Never twice, never forgetting**
- A run that waited in GitHub's queue used to start from the memory of when it was queued, i.e. *before* the run
  ahead of it saved tonight's post. It could then post a second reel and overwrite the memory (losing the post and
  the series progress). Every run now loads the newest memory first, and the memory save always keeps the whole file.
- A second safety net that doesn't depend on the memory: before making and before posting a reel, the system asks
  Instagram when the newest reel went out. If a reel already went out this evening, it stops.
- A damaged memory file no longer stops every later run: the last good copy (`state/history.bak.json`) is used.
- The post is remembered the moment Instagram confirms it (before YouTube).

**Posting**
- Runs that start early upload the reel to Instagram and let it *process* right away; at 9:17 PM only the final
  "publish" is left, so the reel goes out on the minute, and a processing problem is found hours early.
- If Instagram can't process the video, it is asked once more with the same link; status-check hiccups (HTTP 500,
  timeouts) are no longer failures; "publish" is retried, and a lost answer is checked so it can't post twice.
- Instagram first, then YouTube (a slow YouTube upload can't delay Instagram).
- An Instagram outage during the token check is no longer reported as an expired token.

**A weaker reel beats no reel**
- When every writing model is overloaded, the run waits 10 min and tries again (up to 3 times) while there is time.
- If the Critic can't be reached, the writer's draft is used; if no draft reaches the bar, the best safe draft
  (at least `story.last_resort_score: 45`) is posted.
- If the caption writer is down, a simple caption is used. Learning from past posts can't stop a run any more.
- Few free Cloudflare pictures left: a simpler reel with 8 pictures from the backup (AI Horde) instead of stopping.
  AI Horde gets more time when the run has hours to spare (`visuals.aihorde_minutes` minimum), a censored picture no
  longer switches it off for the whole run, and as a last try it draws the place without people (its filter mostly
  reacts to people in horror scenes). Character portraits are skipped when only AI Horde is left (it can't use them).
- The quality check posts reels with reused pictures as long as at least `qa.min_drawn_images: 5` real pictures were
  drawn; a reel that runs long is a warning, not a reason to drop it. Voice speed-up goes up to 15% only if needed
  to stay under 3:00 (a YouTube Short).
- Groq "request too large": retried with a small answer room, enough for reviews and captions.
